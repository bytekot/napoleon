# Этап 7: Предложения по улучшению

Накоплены в ходе планирования. Не блокируют завершение этапа, адресуются в follow-up.

---

## E1. Error handling UI

В store реализована обработка ошибок (`request.status = 'error'`), но UI-отображение отсутствует.
- Vue ErrorBoundary компонент для перехвата unhandled errors
- Toast-уведомления для API ошибок
- Отображение состояния ошибки с retry button

**Приоритет:** Средний (приложение работает, но ошибки не видны пользователю)

---

## E2. Responsive layout

Layout фиксированный (flex + max-width: 250px). На мобильных сайдбар занимает много места.
- Media queries для перестройки на узких экранах
- Collapsible sidebar или drawer pattern

**Приоритет:** Низкий (зависит от требований к мобильной версии)

---

## E3. CSS variables для темы

Цвета захардкожены (#e5e5e5, #999). Вынести в CSS custom properties для упрощения смены темы.

**Приоритет:** Низкий (косметическое улучшение)

---

## E4. Рефакторинг структуры стилей

Вынести общие паттерны в SCSS mixins/partials, убрать magic numbers.

**Приоритет:** Низкий (не влияет на функциональность)
