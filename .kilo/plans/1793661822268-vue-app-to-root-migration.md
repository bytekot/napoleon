# План: Переезд vue-app в корень репозитория

## Цель
Переместить `packages/vue-app` в корень репозитория, сделать его основным проектом. React-app перенести в `/legacy-react`. Сохранить работоспособность всех команд и ссылок.

## Принятые решения
1. **Workspace**: убрать сейчас, вернуть когда появится полноценный backend
2. **React-app**: перенести в `/legacy-react`, запуск только из своей директории
3. **API**: остаётся в `api/`, запускается через `node api/server.js` из корня

## Шаги выполнения

### 1. Подготовка (без изменений кода)
- [ ] Проверить текущее состояние: `pnpm check` в `packages/vue-app` должен проходить
- [ ] Зафиксировать список файлов в `packages/vue-app` для контроля полноты переноса

### 2. Перенос vue-app в корень
- [ ] Скопировать содержимое `packages/vue-app/` в корень (кроме `node_modules/` и `dist/`)
  - Файлы: `src/`, `public/`, `index.html`, `package.json`, `vite.config.ts`, `vitest.config.ts`, `eslint.config.ts`, `tsconfig*.json`, `env.d.ts`, `.prettierrc`, `.gitignore`, `.vscode/`, `README.md`
- [ ] Обновить корневой `package.json`:
  - Взять `package.json` от vue-app как основу
  - Добавить скрипт `"start-server": "node api/server.js"`
  - Убрать префикс `napoleon-vue` из name (опционально, можно оставить)
- [ ] Удалить старый `packages/vue-app/` после проверки
- [ ] Удалить `pnpm-workspace.yaml`

### 3. Перенос react-app в legacy-react
- [ ] Создать директорию `legacy-react/`
- [ ] Переместить `packages/react-app/` → `legacy-react/`
- [ ] Удалить пустую директорию `packages/`

### 4. Обновление конфигураций
- [ ] Обновить `AGENTS.md`:
  - Изменить структуру репозитория
  - Обновить команды разработки (убрать `dev:react`, `dev:vue`, добавить `dev`)
  - Обновить путь для проверок: `pnpm check` теперь из корня
- [ ] Обновить `.kilo/kilo.jsonc`:
  - Изменить `"packages/react-app": "deny"` → `"legacy-react": "deny"`
- [ ] Проверить `.gitignore` — должен работать без изменений (относительные пути)

### 5. Установка зависимостей и проверка
- [ ] Выполнить `pnpm install` в корне (создаст новый `node_modules/`)
- [ ] Выполнить `pnpm check` — lint + format:check + type-check
- [ ] Выполнить `pnpm dev` — проверить что приложение запускается
- [ ] Выполнить `pnpm build` — проверить сборку
- [ ] Выполнить `pnpm test:unit` — проверить тесты
- [ ] Проверить `node api/server.js` — API должен запускаться

### 6. Финальная проверка
- [ ] Проверить все импорты в коде (не должно быть сломанных путей)
- [ ] Проверить что нет упоминаний старых путей в документации/конфигах
- [ ] Убедиться что `legacy-react/` изолирован и не влияет на основной проект

## Риски и точки внимания
1. **Path aliases**: `@/*` alias в vite.config.ts и tsconfig.app.json использует относительные пути — должны работать после переноса
2. **VITE_API_URL**: клиент API использует `localhost:3001` по умолчанию — не меняется
3. **node_modules**: старый `packages/vue-app/node_modules/` удаляется, создаётся новый в корне
4. **IDE**: может потребоваться перезагрузка TypeScript/Vue сервера после переноса

## Критерии завершения
- [ ] `pnpm check` проходит без ошибок
- [ ] `pnpm dev` запускает приложение на localhost:5173
- [ ] `pnpm build` создаёт dist/
- [ ] `pnpm test:unit` проходит
- [ ] `node api/server.js` запускает API на :3001
- [ ] Нет битых импортов в коде
- [ ] AGENTS.md отражает новую структуру
- [ ] legacy-react/ существует и изолирован
