# Переход spacing/size примитивов на модульную шкалу xs/s/m/l/xl/2xl/3xl

## Цель
Заменить числовые имена spacing/size/radius примитивов на семантическую шкалу и перевести значения на модульную сетку.

## Решения

### Шкала spacing/size (единая)
```scss
$space-xs: 4px;
$space-s: 8px;
$space-m: 12px;
$space-l: 16px;
$space-xl: 24px;
$space-2xl: 32px;
$space-3xl: 64px;
```

### Шкала radius (отдельная)
```scss
$radius-s: 4px;
$radius-m: 10px;
$radius-full: 30px;
```

### Маппинг старых значений → новые
**Spacing:**
- `$space-5` (5px) → `$space-xs` (4px, -1px)
- `$space-10` (10px) → `$space-s` (8px, -2px)
- `$space-20` (20px) → `$space-xl` (24px, +4px)
- `$space-30` (30px) → `$space-2xl` (32px, +2px)

**Font-size** (не меняются, только переименование):
- `$font-size-14` → остаётся как есть (не часть spacing-шкалы)
- `$font-size-20` → остаётся как есть

**Radius:**
- `$radius-4` → `$radius-s` (4px, без изменений)
- `$radius-10` → `$radius-m` (10px, без изменений)
- `$radius-30` → `$radius-full` (30px, без изменений)

## Задачи

### 1. Обновить `_primitives.scss`
- Удалить старые переменные `$space-5/10/20/30`, `$radius-4/10/30`
- Добавить новую шкалу `$space-xs/s/m/l/xl/2xl/3xl`
- Добавить `$radius-s/m/full`
- Font-size оставить без изменений (это отдельная категория)

### 2. Обновить `theme.scss`
Заменить все интерполяции:
- `#{$space-5}` → `#{$space-xs}`
- `#{$space-10}` → `#{$space-s}`
- `#{$space-20}` → `#{$space-xl}`
- `#{$space-30}` → `#{$space-2xl}`
- `#{$radius-4}` → `#{$radius-s}`
- `#{$radius-10}` → `#{$radius-m}`
- `#{$radius-30}` → `#{$radius-full}`

### 3. Обновить `docs/theme-architecture.md`
- Отметить задачу «Переход spacing/size примитивов на шкалу xs/s/m/l/xl» как выполненную
- Зафиксировать решение в таблице решений
- Обновить список категорий примитивов

### 4. Проверки
- `pnpm check` — убедиться, что нет ошибок компиляции
- Визуальная проверка не требуется (семантические токены абстрагируют изменения)

## Вне скоупа
- Ревизия хардкодных значений в компонентах (следующая задача после введения шкалы)
- Приведение compound-значений к единой системе (отдельная задача)
- Изменение font-size примитивов (не запрошено)

## Риски
- Визуальные изменения из-за округления: наиболее заметно `$space-20` → 24px (+4px). Компоненты используют семантические токены, поэтому адаптация автоматическая, но стоит проверить ключевые экраны.
