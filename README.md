# Napoleon

Task board with calendar and drag-and-drop UX. Built with TypeScript, Vue 3 and Pinia.

## Development

```bash
pnpm install          # Install dependencies
pnpm dev              # Start frontend (Vite)
pnpm start-server     # Start API server (Express)

pnpm check            # Lint + format check + type check
pnpm build            # Production build
pnpm test:unit        # Run unit tests
