## Задачи этапа 7

### 7.1 Верификация интеграции

Проверить, что все компоненты работают вместе корректно:

1. **Запуск приложения**
   - `pnpm dev:vue` стартует без ошибок
   - `pnpm start-server` запущен параллельно
   - MainPage загружается, отображает TasksForm и Calendar

2. **Проверка загрузки задач**
   - При открытии `/` задачи загружаются из API
   - Список задач отображается в TasksForm (unplanned)
   - Задачи с dueDate отображаются в соответствующих днях календаря
   - Повторный переход на страницу не вызывает дублирующий fetch (guard работает)

3. **Проверка CRUD операций**
   - Создание задачи через TasksForm → задача появляется в списке
   - Редактирование задачи (имя, completed) → изменения сохраняются
   - Удаление задачи → задача исчезает из списка
   - Ошибки API корректно обрабатываются (request.status = 'error')

4. **Проверка навигации календаря**
   - Переключение периодов (week/month/year) работает
   - Навигация вперёд/назад обновляет отображение
   - Задачи корректно перерисовываются при смене периода

5. **Проверка Drag-and-Drop**
   - Перетаскивание из unplanned в день календаря
   - Перетаскивание между днями
   - Перетаскивание внутри дня (reordering)
   - Drop обратно в unplanned (очищает dueDate)

### 7.2 Устранение расхождений с legacy

Сравнить Vue-версию с React-версией визуально:

1. Запустить оба приложения параллельно:
   ```bash
   pnpm dev:react  # :5173
   pnpm dev:vue    # :5174
   ```

2. Проверить соответствие:
   - Расположение TasksForm слева, Calendar справа
   - Ширина сайдбара с задачами (~250-300px)
   - Отступы, цвета, шрифты
   - Поведение minimized состояния TasksForm

3. Зафиксировать обнаруженные расхождения (если есть) и исправить
